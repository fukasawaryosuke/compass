# キャリアノートのスキーマ

このスキーマは、初期版で扱う`career`、`project`、`achievement`ノートを対象にする。値が未確定の場合は推測で埋めず、空値またはノート本文の確認事項として残す。

## 共通ルール

- すべてのノートはYAML Frontmatterの`type`を持つ。
- 日付は`YYYY-MM`または`YYYY-MM-DD`の文字列に統一する。
- `skills`は技術名の配列とする。専用スキルノートは作らない。
- `source_refs`は任意。資料から明確に参照できる場合だけ追加する。
- `visibility`は、応募書類や面接対策に再利用する前の機密性確認に使う。
  - `internal`: 内部情報を含む可能性がある。
  - `review`: 外部向けに利用する前に確認が必要。
  - `external-safe`: 外部向けに利用してよいと確認済み。

## `career`

勤務先・雇用形態ごとの在籍期間を表す。同一勤務先での部署・役職の変化は、別ノートに分けず本文の役割変遷へ記録する。

| プロパティ | 必須 | 型 | 説明 |
| --- | --- | --- | --- |
| `type` | 必須 | `career` | ノート種別 |
| `employer` | 必須 | 文字列 | `career/employers/`の勤務先ノートへのリンク |
| `employment_type` | 必須 | 文字列 | 例: `full-time`、`contract` |
| `period_start` | 必須 | 文字列 | 在籍開始日 |
| `period_end` | 任意 | 文字列 | 在籍終了日。現職の場合は空値 |
| `roles` | 任意 | 配列 | 主な役職・部署・担当の変遷 |
| `skills` | 任意 | 配列 | 使用した主な技術 |
| `visibility` | 必須 | 文字列 | `internal`、`review`、`external-safe` |
| `source_refs` | 任意 | 配列 | 参照できる元資料ノート |

## `project`

職務上または個人の、再利用可能な取り組みを表す。開発、運用、改善、採用、マネジメント、OSS、登壇、技術記事を含む。

| プロパティ | 必須 | 型 | 説明 |
| --- | --- | --- | --- |
| `type` | 必須 | `project` | ノート種別 |
| `scope` | 必須 | 文字列 | `professional`または`personal` |
| `period_start` | 任意 | 文字列 | 開始日 |
| `period_end` | 任意 | 文字列 | 終了日。継続中なら空値 |
| `career` | 任意 | 文字列 | 関連する職歴ノートへのリンク |
| `employer` | 任意 | 文字列 | 関連する勤務先ノートへのリンク |
| `skills` | 任意 | 配列 | 使用した技術・手法 |
| `visibility` | 必須 | 文字列 | `internal`、`review`、`external-safe` |
| `source_refs` | 任意 | 配列 | 参照できる元資料ノート |

`career`と`employer`は個人活動の場合に省略できる。プロジェクト本文には、背景、目的、自分の役割、実施内容、結果を記載する。

## `achievement`

プロジェクトから切り出した、職務経歴書や面接で再利用できる重要な成果を表す。

| プロパティ | 必須 | 型 | 説明 |
| --- | --- | --- | --- |
| `type` | 必須 | `achievement` | ノート種別 |
| `project` | 必須 | 文字列 | 関連するプロジェクトノートへのリンク |
| `skills` | 任意 | 配列 | 関連技術・手法 |
| `visibility` | 必須 | 文字列 | `internal`、`review`、`external-safe` |
| `source_refs` | 任意 | 配列 | 参照できる元資料ノート |

本文には、背景、自分の役割、行動、成果、面接で話す観点を記載する。成果は数値化できない場合でも記録できる。
